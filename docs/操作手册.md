# APMS 操作手册

> **系统入口**：`http://localhost:80/`（UAT）或生产域名  
> **登录账号**：`admin` / `admin123`（默认）  
> **后端服务**：`http://localhost:9080/api`  
> **Actuator 健康检查**：`http://localhost:9081/actuator/health`

---

## 0. 系统概览

### 菜单结构

```
首页（Dashboard）
├── 运动员管理
│   ├── 运动员列表          ← /apms/athlete
│   └── 运动员详情          ← 点列表行展开，完整档案
├── 基础数据
│   ├── 指标库              ← /apms/indicator
│   └── 测试模型库          ← /apms/testModel
├── 测试任务
│   └── 测试任务列表        ← /apms/testTask（含 Item + Member 子模块）
├── 测试结果
│   └── 测试结果列表        ← /apms/testResult（含 CSV 导入 + Attempt history）
├── 体态监测
│   ├── 体态测量            ← /apms/bodyMeasure
│   └── PHV 成熟度记录      ← /apms/phv
├── 体能评价
│   ├── RTP 风险预警        ← /apms/rtp
│   ├── 组合模型            ← /apms/comboModel
│   └── 组合体能评分        ← /apms/comboScore（含报告页 + 打印）
├── 医疗管理
│   └── 医疗记录            ← /apms/medical
└── 报告中心
    └── 报告列表            ← /apms/report（生成 + PDF 下载）
```

### 核心业务数据流

```
  ┌─ 指标库 ─────────────────────────────────┐
  │  indicator ── ref(gender+ageGroup) ── level │
  └──────────────────────────────────────────┘
                  ↓ 引用
  ┌─ 测试模型库 ──────────┐
  │  test-model ── field   │
  └────────────────────────┘
                  ↓ 引用
  ┌─ 测试任务 ──────────────────────────────┐
  │  test-task ── item(测试项) ── member(队员) │
  └────────────────────────────────────────┘
                  ↓ 录入结果
  ┌─ 测试结果 ────────────────────────────────────────┐
  │  test-result ── values(field数值) ── reps(派生)     │
  │    ↓ 自动链路：                                     │
  │    ├── BodyMeasureSync → body_measure               │
  │    ├── PHV tryAutoCalculate → apms_phv_record       │
  │    ├── Khamis-Roche → athlete.predictedAdultHeight  │
  │    ├── RSA 衰减率 → result.values (isDerived='1')   │
  │    ├── autoSelectBest → isSelected='1'              │
  │    └── TaskProgress → task_member.status             │
  └─────────────────────────────────────────────────────┘
                  ↓ 选最佳结果
  ┌─ 组合体能评分 ─────────────────────┐
  │  combo-model ── component ── T-Score │
  │  combo-score ── ref_snapshot         │
  └──────────────────────────────────────┘
                  ↓ 生成
  ┌─ 报告中心 ─────────────────────┐
  │  TEAM_SUMMARY / ATHLETE_DETAIL   │
  │  PDF 生成 + 下载                 │
  └────────────────────────────────┘
```

### 操作
- **点任务行** → 跳转"测试任务列表"
- **点 RTP 队员** → 跳转"运动员详情"或"RTP 预警"

### 业务含义
- `rtpNotAssessedCount` = 未在 apms_rtp_status 表登记过的运动员数
- `bodyMeasureWeekCount` = 最近 7 天内有 body_measure 记录的不同 athlete 数
- 任务进度 = **有至少 1 个 selected result 的 distinct athlete 数** / 任务参测队员数（口径统一，进度永远 ≤ 100%）

## 2. 运动员管理

### 运动员列表 `/apms/athlete`

#### 功能
运动员档案的 CRUD，含预测成年身高展示。

#### 筛选
- 姓名（模糊）
- 性别（男/女）
- 队伍（下拉）
- 状态（在队/离队）

#### 关键列
| 列 | 说明 |
|---|---|
| 头像 | 首字母缩写 + 颜色 |
| 球衣号 | 同队唯一（保存时校验） |
| 队伍 | 所属队伍名 |
| 年龄 | 实时计算（精确到月） |
| 预测身高 | 由 Khamis-Roche 自动计算（有值才显示） |
| 成年身高算法 | khamis-roche-v1 |
| 计算日期 | 上次预测日期 |

#### 新增/编辑
必填：姓名、性别、生日、球衣号、所属队伍  
选填：电话、位置、备注

#### 离队（逻辑删除）
把 `status` 改为 `'1'`，同时关闭所有 athlete_group 当前记录。队员不会被物理删除。

#### 区域说明

2. RTP 状态 + 最近评估日期
3. 体态测量次数 + 最近测量日期
4. 预测成年身高（Khamis-Roche，无值时灰色占位"未计算"）

**Tab 1 — 体态历史**：
- 表格：日期 / 身高 / 体重 / 坐高 / 腿长 / 体脂率 / 数据源

**Tab 2 — PHV 成熟度**：

- 参与过的测试任务 + 完成状态

**Tab 5 — 分组历史**：

**Tab 6 — PHV 手动计算对话框**：
- 点"计算 PHV"按钮

## 3. 基础数据

### 指标库 `/apms/indicator`

#### 功能
管理所有测试指标，含参考值分组（按性别+年龄组）和等级区间。

#### 筛选
- 编码（如 `SPRINT_30M`）
- 分类（形态/素质/机能）
- 状态

#### 指标本体字段
| 字段 | 说明 |
|---|---|
| 编码 | 必填，唯一。如 `HEIGHT` / `SPRINT_30M` / `VJUMP` |
| 名称 | 中文名 |
| 分类 | 形态/素质/机能 |
| 单位 | cm / s / kg / % |
| 方向 | ↑越大越好 / ↓越小越好 / ≈范围最佳 / —仅参考 |
| 数据类型 | decimal / integer / text |
| 采集方式 | manual / device |

#### 参考值（Ref）Tab

**新增 Ref 对话框**：
- 性别：男 / 女
- 年龄组：U14 / U16 / U18 / U21 / SENIOR
- 正常范围：refMin ~ refMax（可选）
- 适用队伍（可选）

**等级（Level）管理**：
- 表格：等级名 / 下限 / 上限 / 操作
- **实时校验**（前端即时提示）：
  - 🔴 min ≥ max（边界矛盾）
  - 🔴 **区间重叠**（两条 level 的 (min, max) 有交集）→ 行背景变红 + el-alert 提示
  - 🟡 **空洞检测**（首尾明确但中间不覆盖）→ el-alert 提示但不阻止
- **后端校验**（写入前再验一次）：同 ref 内 level 名称不能重复 + 两两不重叠
- **一键三档模板**：检测已有档位，补齐缺失的 EXCELLENT/GOOD/NORMAL/ATTENTION/POOR，空区间留给用户填

**方向含义**（后端会根据方向自动选最佳）：
- HIGHER_BETTER：最大值为最佳（如纵跳高度）
- LOWER_BETTER：最小值为最佳（如 30m 冲刺时间）
- REFERENCE_ONLY：形态指标（身高/体重），不参与评分比较

---

### 测试模型库 `/apms/testModel`

#### 功能
管理复杂测试的字段模板（如 YOYO IR1 有多级 shuttle）。

#### 模型本体
- 编码 + 名称 + 分类 + 算法版本 + 协议说明
- `isCombo`："0" 单一指标 / "1" 组合模型（ComboModel 引用）

#### Field Tab
- 表格：字段 Key / 显示名 / 数据类型 / 必填 / 单位 / 排序
- 对话框：fieldKey（如 `shuttle_level`）/ fieldName（如 "Shuttle 等级"）/ dataType（decimal/integer/text）/ unit / sortOrder

## 4. 测试任务 `/apms/testTask`

#### 功能
测试任务管理：任务本体 + 测试项（Item）+ 参测队员（Member）。三层结构完整可操作。

### 任务列表（左侧）
- 表格：任务名 / 日期范围 / 状态 badge（pending/in_progress/completed） / 目标队伍 / 测试项数 / 队员数 / **进度条 + 百分比**
- 进度条计算：`有 ≥1 个 selected result 的 distinct athlete 数 / 参测队员总数`
- 状态大写兼容（后端小写 in_progress → 前端自动映射中文 tag type）

### 任务详情（右侧）

#### Header
- 任务名 + 状态 badge
- 测试项数 / 参测队员数 / 已选完成数
- 目标队伍 / 测试者 / 日期范围 / 备注

#### Tab 1 — 测试项

**工具栏**：[+ 添加测试项] [刷新] | 提示：从指标库或测试模型库选择，加入本任务

**表格 + 行操作**：
| 列 | 说明 |
|---|---|
| # | 序号 |
| 类型 | 指标（蓝）/ 模型（绿） |
| 名称 | code + name + 分类 tag |
| 方向 | HIGHER_BETTER / LOWER_BETTER 等 |
| 必/选 | 必测（红）/ 选测（灰） |
| 排序 | sortOrder |
| 操作 | 改 / 删 |

**添加/编辑对话框**：
- 类型 Radio：指标 / 测试模型 → 动态切换下拉
- 指标下拉：filterable，每项显示 `CODE · name · 分类`
- 模型下拉：同指标
- 必测开关（el-switch）
- 排序（自动取下一个 sortOrder）
- 方向覆盖（可选，不选跟随指标默认方向）

#### Tab 2 — 参测队员

**工具栏**：[单个登记] [批量登记] [刷新] | 目标队伍：201

**表格 + 行操作**：
| 列 | 说明 |
|---|---|
| 姓名 | name |
| 性别 | ♂/♀ + 颜色（男蓝女粉） |
| 队伍 | athleteTeam |
| 状态 | pending/partial/completed tag |
| 操作 | 改状态 / 离队 |

**单个登记对话框**：
- athlete 下拉（filterable，显示 name + gender + team）

**批量登记对话框**：
- el-select multiple + filterable
- 自动预选已登记队员（让用户直观看到）
- 提示：已选 X 人 · 已在名单中的队员自动跳过（幂等）

## 5. 测试结果 `/apms/testResult`

#### 功能
查看、录入、批量导入测试结果。支持同项目多 attempt + 手动选最佳。

### 左侧 — 搜索栏 + CSV 导入按钮

**筛选条件**：
- 关联任务（下拉）
- 运动员（filterable 下拉）
- 指标（下拉）
- 选中状态（全部/已选/备选）
- 测试日期范围

**CSV 批量导入按钮**（绿色）：
- 点击 → 弹出 CsvImportDialog
- Drag & Drop 区域，accept=.csv
- 内置 CSV 格式说明 + "查看 CSV 格式示例"弹窗
- 上传后自动解析后端返回的 `writtenResultCount / rowsProcessed / warnings / errorRows`
- 成功后自动 reload 左侧列表

### CSV 格式示例
```
athlete_id,measure_date,session_key,HEIGHT,WEIGHT,SPRINT_30M,VJUMP,RSA_10X20
1001,2026-09-18,S1,178.5,72.3,4.85,55.2,3.2
1006,2026-09-18,S1,182.0,78.5,4.60,60.5,3.0
```
- Header 自动匹配 `indicator.code` 或 `test-model.code`（大小写不敏感）
- 列可以是任意顺序
- 不需要的列可以省略

### 左侧 — 结果列表
- 表格：运动员 / 任务 / 指标 / 日期 / 是否选中 ★ / 数据来源 / 操作（编辑/删）
- 点击行 → 右侧面板展开详情

### 右侧 — 详情面板

**Header**：
- 运动员头像 + 姓名 + 性别
- 任务名 + 测试项 + 指标名 + 方向 badge
- 日期 + attemptNo + sessionKey + isSelected

**Values 表格**：
- fieldKey / fieldName / numericValue / unit
- 派生字段（如 RSA Sdec）灰色背景 + "派生" tag

**Attempt History 表格**（关键功能！）：
- 同 athlete + taskItemId 下的所有 attempt
- 列：尝试号（★选中/#备选） / 日期 / 状态（✓已选/备选） / **值（numericValue）** / 方向 / 操作
- **操作列：选为最佳**（仅非选中行显示）
  - 点 → 弹确认对话框"确认切换？原选中项将被覆盖"
  - POST `/apms/test-result/select-attempt/{id}`
  - 成功后自动刷新两侧列表
- **底部提示**：💡 自动选最佳按方向（如 ↓越小越好）。手动点击选为最佳可覆盖。

## 6. 体态监测

### 体态测量 `/apms/bodyMeasure`

#### 功能
运动员身高/体重/坐高等体态数据录入。

#### 列表
- 表格：日期 / 运动员 / 身高 / 体重 / 坐高 / 腿长 / 体脂率 / 数据源 / 操作
- 排序：measureDate DESC

#### 新增/编辑
- athlete（filterable 下拉）
- measureDate
- height / weight / sitHeight / waist / bodyFatRate / ...
- dataSource（manual/csv/device）
- remark

#### 自动触发链路（后端静默）
每次 upsert 或 CSV 同步后：
1. **PHV tryAutoCalculate**：height + sitHeight + weight + birthday 齐了 → Mirwald 公式算成熟度偏移 + 预测 PHV
2. **Khamis-Roche**：同上齐项 → 预测成年身高 → 写回 `athlete.predictedAdultHeight`
3. **幂等**：同 `body_measure.id` 只触发一次

#### 删除级联
删 body_measure → 自动删关联 PHV 记录（`apms_phv_record.source_measure_id`）

---

### PHV 成熟度 `/apms/phv`

#### 功能
查看运动员的 PHV 历史记录（由 body_measure 自动触发，也可手动计算）。

#### 列表
- 表格：运动员 / gender / 日期 / decimalAge / predPHV / **offset（正负颜色）** / algo / source_measure_id

#### 手动计算
- 运动员详情页 → Tab6 PHV 手动计算对话框
- 自动查最新 body_measure 填入参数
- 显示 Mirwald + Khamis-Roche 双算法输出

#### offset 含义
| offset | 含义 | 颜色 |
|---|---|---|
| > 0 | 已过 PHV 期（late-puberty） | 绿色 |
| ≈ 0 | 正在 PHV 期 | 黄色 |
| < 0 | 尚未到 PHV 期（pre-puberty） | 红色 |

## 7. 体能评价

### RTP 风险预警 `/apms/rtp`

#### 功能
运动员 RTP（Return To Play）状态管理。

#### 列表
- 表格：姓名 / 性别 / 队伍 / **状态 badge**（绿/黄/红）/ 原因 / 训练限制 / 下次复查 / 更新时间
- 黄色提醒 + 红色警告 + 灰色未评估

#### 操作
- **改状态**：el-dialog 弹状态选择（green/yellow/red）+ 原因 + 训练限制 + 下次复查日期
- **清除状态**：回到"未评估"

#### 历史 Tab
- 状态变更日志：from → to + reason + 操作人 + 时间

---

### 组合模型 `/apms/comboModel`

#### 功能
管理组合体能评分模型（如 composite-fitness-v2）。

#### 模型本体
- 编码 + 名称 + 算法版本 + 归一化方法（Z_SCORE/MINMAX）+ 公式说明

#### Component Tab
- 表格：序号 / 指标（code + name + 方向）/ 权重 / 方向覆盖 / 操作
- **权重合计自动校验**（weightSum != 1.0 时 el-alert 黄色提醒）
- 对话框：indicator filterable 下拉 + weight（0~1）+ directionOverride

---

### 组合体能评分 `/apms/comboScore`

#### 功能
触发组合分计算 + 可视化报告页。

#### 列表
- 表格：运动员 / 队伍 / comboScore（**格式化 + 分级**）/ comboGrade / calculatedAt / 模型名 / 操作
- comboScore 分级：
  - ≥1.0 → 🏆 优秀
  - ≥0.3 → ✅ 良好
  - >-0.3 → ➡️ 正常
  - >-1.0 → ⚠️ 需关注
  - ≤-1.0 → 🔴 较差

#### 触发计算按钮
- 右上角绿色 [💻 触发计算] 按钮
- 对话框：选 comboModel + 选 task → POST `/combo-score/calculate`
- 结果弹窗：成功 X 人 / 跳过 Y 人 + 每人 comboScore 预览

#### 报告页（点行 → Snapshot 按钮 → 弹窗）

**完整可视化报告**：

```
│                    │  2.563  │ ← comboScore   │
│                    │ 🏆 优秀 │ ← comboGrade    │
│                    └─────────┘                │
├─ T-Score 条形图 ─────────────────────────────┤
│ SPRINT_30M ┃◄──35.9(T) ── 50 ─────► ┃ Z=-1.41 │
│ VJUMP      ┃        ───── 50 ──► 62.8(T) ┃ Z=1.28 │
│ RSA_10X20  ┃◄──34.2(T) ── 50 ─────► ┃ Z=-1.58 │
├─ 逐指标计算明细（表格）─────────────────────┤
│ │指标│方向│w│值│ref│μ/σ/N│Z│T│ws│贡献%│      │
│ │SPR│↓越│0.34│3.72│3.5~5.0│4.25/0.375/N=4(ref)│-1.41│35.9│0.48│■■■│
├─ 数据来源说明 ───────────────────────────────┤
│ ℹ️ 真实统计：同队伍+性别 数据 N=8 ≥ 5，使用 μ/σ │
│ ℹ️ ref 代理：N=3 < 5，使用 ref_min/ref_max 代理 │
└───────────────────────────────────────────────┘
  [🖨️ 打印报告]  [关闭]
```

**关键可视化**：
- T-Score 条形图：30~70 映射 0~100%，中心 50 有竖线；绿色=好于均值，红色=差于均值
- Z-Score 颜色：Z≥0.5 绿，Z≤-0.5 红
- useRealStats 标记：N≥5 绿色"真实"标签 vs N<5 灰色"ref"标签
- 贡献度条形：el-progress 显示各 component 在加权总分里的占比
- 跳过 component：灰色背景 + skipReason 文案
- **打印按钮**：`window.print()` + `@media print` 隐藏 dialog header/footer

#### T-Score 算法说明
- T = 50 + 10 × Z，Z = (raw − μ) / σ
- μ/σ 优先取 **同队伍 + 同性别** 范围内 ≥ 5 条真实数据
- 不足 5 条回退 ref_min/ref_max 代理

## 12. 常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| CSV 导入报 "indicator XXX 未配置" | CSV header 没匹配到 `indicator.code` 或 `test-model.code` | 确认 code 拼写（大小写不敏感） |
| PHV 没自动算 | body_measure 缺 sitHeight 或 athlete 缺 birthday | 补坐高 → 下次 upsert 自动触发 |
| Khamis-Roche 预测值 < 当前身高 | late-puberty（~17 岁）正常，男孩平均还有 1-2cm 生长空间 | 观察下次测量后是否收敛 |
| indicator level 报"区间重叠" | 新 level 和已有 level 的 (min,max) 有交集 | 调整 min/max 使所有 level 两两不重叠 |
| testTask item 方向不生效 | directionOverride 留空时跟随指标默认方向 | 指标库改 evaluationDirection |
| 任务进度 240% | 口径不一致（修好了） | 重启 UAT 或清 Redis 缓存 |
| attempt 没自动选最佳 | indicator 缺 evaluationDirection | 在指标库配置方向 |
